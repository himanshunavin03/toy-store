## Visual system and production rules

Palette proposal: warm ivory #FFF9F3, deep ink #27304A, coral #F27B70, powder blue #B9DDEB, muted lilac #DCCDF5, butter #F6E4A6. Visual language: refined editorial still life, believable objects, tactile surfaces, soft daylight, clean negative space, playful accents. Product listings use consistent ivory/pastel seamless backgrounds and true-to-record details. Do not render text or logos inside generated photography; set copy and buttons as accessible Wix Studio elements. For generated logos, use the output only as a sketch: finalize lettering as an original vector mark and check brand legibility.

For every prompt below, append this exact negative direction: **No text, no watermark, no third-party logo, no copyrighted or licensed character, no Harsh Stores resemblance, no extra malformed objects, no fabricated certification or performance claim.** This sentence is part of each exact generation brief. Use WebP/AVIF for final static site media where Wix accepts it; keep editable high-resolution masters separately. Upload approved media to Wix Media. A repository asset alone is not displayed by the Wix canvas. Use responsive crop rather than stretching. Compress to a useful quality/size and inspect final assets on mobile.

Status meanings: **Concept generated** = a local concept file exists but is not approved/uploaded; **Brief only** = no asset generated or uploaded. The only generated file is assets/anh-vibes/hero-desktop-concept.png, approximately 2:1, as a proposed hero visual. It has **not** been attached to Wix Media, Product Pages, or the live site.
